# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities through GitHub's private reporting: go to the **Security** tab of this repository and click **Report a vulnerability**. We aim to acknowledge reports within 3 business days.

This covers the code in this repository (SDKs, CLI, validation scripts). Issues with the hosted PromtExpress service can be reported the same way; we will route them internally.

## API keys

Never paste a real API key into an issue, pull request, test or example. If you leak one, revoke it immediately in the PromtExpress dashboard under **API Keys** and create a new one.
