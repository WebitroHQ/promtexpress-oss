# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, assume good intent, critique ideas rather than people, and do not harass anyone. This applies in issues, pull requests, discussions and any other project space.

## Reporting

If someone's behavior makes you uncomfortable, report it privately to the maintainers using the contact email on the [WebitroHQ GitHub organization profile](https://github.com/WebitroHQ). You can also use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature.

All reports are handled confidentially. Maintainers may remove comments, close issues or ban contributors who violate this code, as described in the Contributor Covenant's enforcement guidelines.
